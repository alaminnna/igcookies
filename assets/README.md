# assets

Static media used by the igcookies extension README.

| File | Description |
|:--|:--|
| `guide-download.mp4` | Short screen recording showing how to download the extension from GitHub. Linked from the root `README.md` Download section. |
| `guide-download-preview.png` | Thumbnail preview for the download video. Displayed as a clickable image linking to `guide-download.mp4`. |

## Usage

Embed the video in documentation with the preview image as the clickable poster:

```markdown
<a href="assets/guide-download.mp4">
  <img src="assets/guide-download-preview.png" width="720" alt="Watch the download guide" />
</a>
```

Replace files here only when updating the download guide; keep filenames stable so existing README links keep working.
